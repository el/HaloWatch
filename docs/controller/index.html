Wi-Fi

The watch turns Wi-Fi on only while it needs it (assistant, weather, time) and off when idle. 2.4 GHz networks only. With more than one network set, it uses the strongest one in range.

Assistant (Gemini Live)

Hold BOOT on the watch, talk, release; the answer is spoken. Get a free API key at aistudio.google.com → “Get API key”.

Sound

“Mic test” records 3 seconds and plays them back; the level appears in the log.

Weather

Up to four places, from Open-Meteo. “City”, “City, Country” or “latitude, longitude”. The first one is on the watch face.

Clock

The time comes from the internet (or this page). Time zone “Auto” follows the first weather place.

Calendar

A private iCal link: in Google Calendar, Settings, your calendar, "Secret address in iCal format"; in iCloud, share the calendar publicly and copy its link. The watch shows the next 7 days and reads it again with the weather.

Home Assistant

The Home app switches these. The address with its IP (the watch does not resolve .local names), a long-lived access token (your Home Assistant profile, Security), and the entities, separated by semicolons.
